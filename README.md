# Love That Is Harmed

Naming my feelings. Journal prompt #2.

**Live page:** https://eldarttyy.github.io/love-that-is-harmed/

Written for RELI 230 at Pacific Lutheran University (Fall 2026) and presented as a single-page website.

Built with plain HTML, CSS and JavaScript — no framework, no build step. Hosted on GitHub Pages.

To view locally, open `index.html` in a browser, or run `python3 -m http.server` in this folder.
